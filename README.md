# 未实现的人生

中文互动人生小说，从2000年、24岁开始，走到2020年。人物、雇主与私人经历均属虚构；市场历史独立于玩家选择。

- 公开入口：https://a1459000683-art.github.io/the-unrealized-life/
- 备用入口：https://the-unrealized-life-2000.a1459000683.chatgpt.site

这些是项目公开入口；本打包程序不进行上传或网络验证，不能据此判断线上是否已更新到本包版本。

本包静态内容实读为 **3种开局、100个节点、300个选项、77组场景、23个条件变体、13条跨年链、10种结局**。这些是源码中的内容数量，不冒充独立实测可达数量；多数完整路线有约77次选择，部分路线会提前结束。

与本包源码、数据及路线文件哈希一致的独立重播，实际执行12条路线、922次选择，覆盖100个节点、23个变体、10种结局和13条链。选项覆盖为 **230/300**；其余70个选项未由这组路线逐一执行，不能称作全部选项已测。

## 打开与保存

直接用能执行JavaScript的浏览器打开 `index.html`，不需要安装npm包、账号、API或网络。游戏是完整离线单文件，剧情不是运行时生成；普通文件预览器不一定能运行。`legacy.html`保留旧玩法与旧存档身份，`legacy-v1.1.html`是原样冻结版本。小说与旧版存档不混用。

自动书签、手动书签及JSON导入导出可用。不同网址、设备与离线文件的存储空间不会自动同步；跨入口前先导出。浏览器限制file地址存储、隐私模式、权限或配额不足时，当前页临时进度不等于永久保存。多标签页冲突会提示，不能当作自动同步。

`connection-check.html`是轻量连接检查页。已有用户反馈手机可以顺利打开；这是单次设备打开反馈，不是实体手机完整通关验收，也不保证所有Safari/WebView版本或中国大陆网络可用。手机阅读布局和桌面手机视口测试有各自范围。连接问题可先打开检查页，也可下载离线文件；离线仍需浏览器支持JavaScript。

## 历史资料边界

16家核心公司覆盖2000-01-03至2020-12-31的53个真实采样日期，另有有限交易窗口的清算案例。缺失价格不可交易，不用合成或插值价格充当真实收益。早期财务按原始公开日开放，未知指标保留空值；不同产业现金和债务口径见来源文件。

股票采用还原的当时收盘价，分红和拆股另行入账；分红入账简化为除息日。基准使用含再投资的复权序列，不再重复计息。回撤只代表离散节点。未模拟所得税、资本利得税、通胀及完整经纪业务流程。客户组合、机构收入与个人资金分开核算；净资产增加不全是投资回报。

来源、逐节点追溯与限制见 `docs/SOURCES.md`。源码包提供公开行情/SEC数值JSON、短数字证据、来源链接与原件哈希，**不重复分发整篇年报**。匿名只是阅读设计，查看源码会看到真实公司身份。

## 源码与复核

解压 `source-and-public-data.zip` 后，源码直接位于压缩包根目录。游玩无需任何工具；重建需要本地Node.js，数据重建需要Python 3，均不需要npm安装：

```text
node build.cjs
node --test tests/*.test.cjs
node tests/novel-story-replay.cjs
node tests/novel-real-careers.cjs
node tests/novel-real-finance.cjs
python3 scripts/build_market.py
python3 scripts/audit_market.py
```

先在解压目录运行命令；`build.cjs`也会重建兼容旧版。数据重建不联网，使用随包数值证据。`MANIFEST.sha256`用于校验包内文件，`PUBLIC_PACKAGE.json`记录内容数量、纳入文件和省略项目。运行测试会产生新的本地报告，打包时未附带开发者本机QA日志。

`tests/fixtures`与三份 `output/playwright/*-save.json`是默认测试需要的虚构游戏存档/版本夹具，特意保留。需要完整原件的逐行Python审计和依赖本机浏览器会话的流程，不属于上述离线测试；详见 `docs/PUBLIC_PACKAGE.md`。

只准备上传目录可运行 `python3 scripts/package_public.py`。它不构建、不联网、不发布；现有HTML必须与源码和数据一致。准备结果是 `output/github-upload/` 的7个文件。压缩包带有fflate的MIT许可：`docs/FFLATE_LICENSE.txt`。
